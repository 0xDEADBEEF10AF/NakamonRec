NakamonREC Privacy Policy / プライバシーポリシー

Last updated: 2026-09-27

日本語

NakamonREC (以下「本アプリ」) は、スマートフォン向けゲーム「ドラゴンクエストウォーク」の 「なかまモンスター」対戦画面を解析し、ユーザー自身の対戦戦績を記録する、 ファンによって個人制作された非公式の分析ツールです。本アプリは株式会社スクウェア・エニックス様の 公式アプリではなく、公式からの協賛・提供は一切受けていません。

1. 取得・収集する情報

本アプリは、以下の情報を一切収集しません。

  • 個人情報 (氏名、メールアドレス、住所、生年月日等)
  • 端末識別子 (IDFA、IDFV 等)
  • 位置情報
  • 連絡先・写真・カレンダー等のデバイスデータ
  • クラッシュレポート・利用統計・解析データ

2. 画面解析について

本アプリは、OS が提供する画面ブロードキャスト機能 (iOS: Broadcast Upload Extension、Android: MediaProjection API) によって取得した 画面映像を解析しますが、以下のとおり完全にローカルで処理を完結します。

  • 解析処理はすべて端末内ローカルで実行されます
  • 動画ファイル・スクリーンショット画像は一切外部に送信されません
  • 解析結果 (対戦戦績データ) は端末内のアプリ専用領域にのみ保存されます
  • 画面映像・解析結果・戦績データのためにネットワーク通信を行うことはありません

3. ネットワーク通信について

本アプリが行うネットワーク通信は、以下のアップデート確認に限られます。 いずれもアプリストアが提供する公開 API であり、ユーザーのデータ (戦績・画面映像・個人情報) は 一切含まれません。

  • iOS: Apple の iTunes Lookup API (itunes.apple.com) に本アプリの Bundle ID を送信し、App Store 上の最新バージョン情報を取得します
  • Android: Google Play の In-App Update API を通じて、Google Play 上の最新バージョン情報を取得します

これらの通信は Apple / Google のサーバーとの間で行われ、通信に伴い接続元の IP アドレス等が 各社のプライバシーポリシーに従って取り扱われる可能性があります。開発者がこれらの通信内容を 受け取ることはありません。アップデート確認は起動時に自動で行われるほか、アプリ内から手動で 実行することもできます。

また、アプリ内の「使い方はこちら」等のリンクは端末の Web ブラウザを起動して開きます。 その際の通信は本アプリではなくブラウザが行います。

4. データの第三者提供

本アプリは、上記のアップデート確認以外に外部サーバーとの通信を行いません。 ユーザーの戦績データ・画面映像・個人情報が第三者 (Apple、Google、開発者本人を含む) に 提供・送信されることはありません。

5. データの保管期間

すべての戦績データは、ユーザーの端末内にのみ保存されます。ユーザーがアプリを アンインストールした時点で、すべてのデータは端末から削除されます。 バックアップサーバー等への保存は一切行われません。

6. 子供のプライバシー

本アプリは特定の年齢層を対象とせず、ユーザーから情報を収集することもないため、 COPPA (米国児童オンラインプライバシー保護法) に該当する情報の取得は発生しません。

7. プライバシーポリシーの変更

本ポリシーの内容は、必要に応じて変更されることがあります。変更があった場合、 本ページ上で最終更新日を改定して告知します。

8. お問い合わせ

本ポリシーまたは本アプリに関するお問い合わせは、下記の GitHub Issues ページよりお願いいたします。

English

NakamonREC ("the App") is a non-official fan-made analysis tool that records the user's own battle results in the "Companion Monster" battle mode of the mobile game Dragon Quest Walk. The App is NOT an official Square Enix product and has no affiliation with or sponsorship from Square Enix.

1. Information We Collect

The App does NOT collect any of the following:

  • Personal information (name, email, address, date of birth, etc.)
  • Device identifiers (IDFA, IDFV, etc.)
  • Location data
  • Contacts, photos, calendar, or other device data
  • Crash reports, usage statistics, or analytics data

2. Screen Analysis

The App uses OS-provided screen broadcast features (iOS: Broadcast Upload Extension, Android: MediaProjection API) to analyze screen frames, but all processing is performed entirely on-device:

  • All analysis runs locally on the device
  • No video files or screenshots are transmitted externally
  • Battle records are stored only in the App's local sandbox
  • The App performs no network communication for screen frames, analysis results, or battle records

3. Network Communication

The only network communication performed by the App is the update check described below. Both use public APIs provided by the app stores, and no user data (battle records, screen frames, or personal information) is included.

  • iOS: The App sends its Bundle ID to Apple's iTunes Lookup API (itunes.apple.com) to retrieve the latest version available on the App Store
  • Android: The App retrieves the latest version available on Google Play via the Google Play In-App Update API

These requests are exchanged with Apple / Google servers, and connection metadata such as the IP address may be handled under their respective privacy policies. The developer does not receive any of this traffic. The update check runs automatically at launch and can also be triggered manually from within the App.

Links inside the App (such as "How to use") open in the device's web browser. Any communication that follows is performed by the browser, not by the App.

4. Third-party Data Sharing

Apart from the update check above, the App does not communicate with any external server. No battle records, screen frames, or personal information are shared with or transmitted to any third party, including Apple, Google, or the developer.

5. Data Retention

All battle data is stored only on the user's device. When the user uninstalls the App, all data is removed from the device. No data is retained on any backup server.

6. Children's Privacy

The App does not target any specific age group and collects no information from users, so no information subject to COPPA is acquired.

7. Changes to This Policy

This policy may be updated as necessary. When updated, the "Last updated" date on this page will be revised.

8. Contact

For inquiries about this policy or the App, please use the GitHub Issues page below.
